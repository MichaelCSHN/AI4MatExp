# AI4MatExp 项目章程

## 项目目标

AI4MatExp 建设一个面向《AI 时代的材料实验：从自动到自主》的完整课程平台，支撑 13 周教学、案例讨论、项目推进、学生贡献和教师复用。

## 核心受众

- 材料科学与工程研究生
- 高年级本科生
- 任课教师与助教
- 对 SDL / AI4Materials 教学感兴趣的外部学习者

## 成功标准

- 学生能沿着网站完成从研究问题卡到最终项目展示的连续旅程。
- 每周页面都能支撑一次真实课堂活动，而不只是阅读材料。
- 每个技术概念都有对应的判断任务、模板或案例。
- AC Microcourses 被清晰地用作前导和外援，而不是被复制为正文。
- 教师能够依据材料包复用或改造课程。

## 非目标

- 不做 AC Microcourses 的中文版。
- 不做纯文档站。
- 不做单次讲座页面。
- 不追求第一版就覆盖完整 LMS 功能。
