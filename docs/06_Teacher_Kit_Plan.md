# 教师材料包方案

## 每周教师包结构

| 材料 | 内容 |
|------|------|
| 课前准备 | 学生需要读什么、装什么、带什么数据 |
| 触发脚本 | 开场问题和引入方式 |
| 活动流程 | 每 10-15 分钟的课堂组织 |
| 追问清单 | 教师必须问的问题 |
| 常见误区 | 学生最可能误解的点 |
| 评分样例 | 优秀、及格、问题样例 |
| 风险提示 | AI、数据、实验安全或伦理风险 |

## 教师视图原则

教师材料不应只是答案，而应提供追问方式。课程的核心不是把学生引向标准答案，而是让学生能说明自己的判断依据和边界。

## 优先生成周次

1. 第 0 周：预备包
2. 第 3 周：DOE 审计
3. 第 6 周：GP 直觉
4. 第 7 周：A-Lab 辩论
5. 第 11 周：风险与责任
