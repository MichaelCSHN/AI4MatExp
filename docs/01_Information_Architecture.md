# 信息架构

## 顶层结构

| 模块 | 作用 |
|------|------|
| 课程驾驶舱 | 展示课程阶段、周次、交付物、项目轨道和外援入口 |
| 13 周地图 | 按周组织问题、活动、模板和交付节点 |
| 判断工作台 | 承载 DOE 审计、GP/BO 判断、PAVE-R、Risk Register 等工具 |
| 案例现场 | 支撑 A-Lab、GNoME、失败 BO 等案例辩论 |
| 项目工作台 | 支撑四条项目轨道和里程碑推进 |
| AC 外援 | 链接并引导使用 AC Microcourses |
| 教师材料包 | 提供课堂脚本、追问清单、评分样例和常见误区 |

## 页面原则

每个页面都应明确：

- 本页训练什么判断？
- 学生要完成什么动作？
- 产出进入哪个交付物？
- 是否需要 AC 外援链接？
- 教师应如何追问？

## 导航原则

桌面端采用可折叠左侧导航。导航状态不仅是目录，还应提示：

- 页面类型
- 当前课程阶段
- 是否有工具
- 是否有模板
- 是否有 AC 外援
- 是否有项目交付物
