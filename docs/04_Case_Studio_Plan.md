# 案例工作台方案

## 设计目标

案例工作台不是论文阅读页，而是课堂辩论和判断训练工具。每个案例都应包含角色、证据、争议点和迁移问题。

判断力训练需要"何时不该信"与"何时该信"成对出现——案例库必须同时包含争议案例与正面对照案例。

## 首批案例（v3.2：4 → 5 个）

| 案例 | 类型 | 训练目标 |
|------|------|---------|
| A-Lab 成功率争议（2023-2026 完整弧线） | 争议 + 真实裁决 | 判断 SDL 成功率、再分析、指标、责任与编辑裁决 |
| GNoME 批判（争议进行中） | 争议（无裁决） | 判断顶刊 AI 发现声明的边界；新颖性-可信性-实用性三元判据 |
| 分布式闭环发现激光材料（*Science* 2024） | **正面对照** | 判断一个"做对了"的 SDL 案例好在哪里：性质目标、器件验证、跨实验室可复现 |
| 失败 BO | 内部演练 | 判断模型失配、采集函数误导和负结果价值 |
| 错误成功判定 | 内部演练 | 判断代理指标、Goodhart 困境和人类 veto 点 |

## 案例页面结构

- 案例背景
- 争议核心
- **时间线（timeline）**：案例事件按时间排列；A-Lab 案例需呈现 2023 发表 → 2023-12 质疑 → 2024 PRX Energy 批判 → 2026-01 Nature 更正 → 更正后余留分歧
- 角色卡
- 证据卡（**可分阶段发放**：辩论时只发裁决前的证据）
- 课堂投票
- **裁决揭晓（verdict）**：真实世界结局（已更正 / 争议中 / 无行动），支持"先辩论后揭晓"交互
- 追问清单
- 课后反思
- 可迁移判断准则

## A-Lab 案例证据卡（五张，前四张辩论用，第五张揭晓用）

1. 原论文关键图表与 71%/41 种新材料宣称（*Nature* 2023）
2. Palgrave 对 XRD 自动解析的即时质疑（2023-12）
3. Leeman 等再分析：约三分之二"新材料"疑为已知无序相（*PRX Energy* 2024）
4. 双方公开回应与媒体报道（2024）
5. **揭晓卡**：Author Correction（*Nature* 2026-01-19，标题 novel → inorganic）+ C&EN 报道 + Palgrave"接受更正但无序问题未被回应"

## 可迁移判断准则（跨案例提炼）

- A-Lab 与 GNoME 栽在同一盲区：**成分无序**，由经典固态化学知识识别——AI 系统的盲区在未被编码的领域知识里（衔接第 10 周 L1-L6）。
- 维护提醒：争议案例的状态会变（GNoME 撤稿呼声仍在演化）。每个案例登记"最后核验日期"，开课前复核。
