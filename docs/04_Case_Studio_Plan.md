# 案例工作台方案

## 设计目标

案例工作台不是论文阅读页，而是课堂辩论和判断训练工具。每个案例都应包含角色、证据、争议点和迁移问题。

## 首批案例

| 案例 | 训练目标 |
|------|---------|
| A-Lab 成功率争议 | 判断 SDL 成功率、再分析、指标和责任 |
| GNoME 批判 | 判断顶刊 AI 发现声明的边界 |
| 失败 BO | 判断模型失配、采集函数误导和负结果价值 |
| 错误成功判定 | 判断代理指标、Goodhart 困境和人类 veto 点 |

## 案例页面结构

- 案例背景
- 争议核心
- 角色卡
- 证据卡
- 课堂投票
- 追问清单
- 课后反思
- 可迁移判断准则
