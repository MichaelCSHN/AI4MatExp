# AI4MatExp

AI4MatExp is the course-platform edition of **AI 时代的材料实验：从自动到自主**.

This repository is separate from `sdl-lecture`:

- `sdl-lecture`: lecture/demo edition for the existing talk site.
- `AI4MatExp`: course-platform edition for the 13-week course, projects, templates, case studios, and teacher kit.

## Current Scaffold

- Vite + React + TypeScript
- Course cockpit with collapsible desktop sidebar
- Data-driven course map in `src/content/courseStructure.ts`
- Migrated course planning materials under `docs/`
- Course build plan in `课程建设方案.md`
